# System Tab

System tab manages device-level restrictions and hard policy toggles.

## Typical Controls

- Camera and capture restrictions
- Keyguard/lock-task-related restrictions
- USB data and user restriction controls
- FRP/owner policy related controls (when supported by device/ROM)

## Operational Notes

- Device-owner APIs vary by vendor ROM.
- Some controls require relaunch or reboot to fully apply.
- Keep policy changes minimal and staged on production fleets.
