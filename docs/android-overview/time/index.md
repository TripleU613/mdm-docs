# Time Management Tab

Time Management controls when apps are allowed to run.

## Enablement

- Turn on global time management to enforce app time policy.
- Device time changes are restricted while policy enforcement is active.

## Policy Types

### Clock Windows

- Define one or more allowed/blocked windows per app.
- Configure day-of-week behavior per window.

### Countdown Timer

- Set countdown limits per app.
- Timer modes include:
  - **App in use**
  - **Also app closed**

## Enforcement

- When time is not allowed, app launch is forced out (jump-out + toast).
- Time-controlled status is visible in Apps tab.
- Policies sync with website time controls.
