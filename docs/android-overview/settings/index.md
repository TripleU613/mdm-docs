# Settings Tab

Settings contains account, maintenance, profile, and UI controls.

## Main Areas

- Language and appearance preferences
- Account and PIN operations
- Profile export/import
- Update checks and maintenance actions
- Policy/legal links

## Profile Export and Import

Current profile export/import is intended to carry full policy configuration state (not device identity).

Use profile operations carefully and validate after import on a test device before production rollout.

## Maintenance

- Manual update checks
- Cache maintenance
- App/service health checks

## Destructive Operations

Uninstall and account deletion actions are destructive. Confirm fleet impact before use.
