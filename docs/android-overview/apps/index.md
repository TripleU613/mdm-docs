# Apps Tab

Apps tab is the per-package policy hub.

## Views

- All apps
- User apps
- System apps
- Managed state indicators

## Common Actions

- Hide/unhide
- Suspend/unsuspend
- Uninstall block toggles
- Kiosk allowlist assignment
- In-app browser policy alignment

## Time Policy Integration

Apps with configured time policy show a **time-controlled** indicator.

- Indicator means schedule and/or timer policy exists.
- Clearing time control removes enforcement for that package.
