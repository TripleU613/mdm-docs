# Network Tab

Network policy is centered on the local PCAP-based filtering stack.

## Current Model

- Local VPN/PCAP enforcement path is the active model.
- App include/exclude behavior can be configured for filtering scope.
- Domain/URL list policy supports import/export workflows.
- Private DNS policy can be enforced where supported.

## Important

- Legacy WireGuard/premium flow is no longer the active path for new deployments.
- Keep network policy aligned with website settings to avoid drift.
