# Remote Control

Remote Control provides live session access where enabled.

## Preconditions

- Remote access entitlement is enabled for the device.
- Device is online with stable network.

## Session Runbook

1. Start session deliberately.
2. Perform required operation.
3. End session cleanly.

## Common Issues

- Blank/black view: permission/session initialization issue.
- High latency: weak network path.
