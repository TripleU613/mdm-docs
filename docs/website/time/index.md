# Time Management Tab (Website)

Website Time Management mirrors Android time policy enforcement.

## Flow

1. Enable global time management.
2. Add one or more apps.
3. Configure schedule windows and/or countdown timers.
4. Save and sync policy.

## Policy Model

- Multiple windows per app are supported.
- Timer policy can be used with or without clock windows.
- Apps tab shows time-controlled status based on saved policy.

## Enforcement Result

When outside allowed time, target apps are forced out on launch/open and user sees policy feedback.
