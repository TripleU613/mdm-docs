# VPN and Network Filtering Status

This section reflects current transition state.

## Current Path

- Active network enforcement path is local **PCAP-based** filtering.
- Device-side network policy is primarily managed through Network tab settings.

## Legacy Path

- Older website VPN controls still exist for some accounts/devices.
- Legacy controls are transitional and should not be used as the baseline for new deployments.

## Explicit Removal Note

WireGuard/premium-VPN framing is not the current recommended model for documentation or new setup.
