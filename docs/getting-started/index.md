# Getting Started

Use this sequence for first-time setup.

## Setup Order

1. Review [Terms and Privacy](/getting-started/terms/).
2. Complete [Account Setup](/getting-started/account/).
3. Grant required [Permissions and Installation Rights](/getting-started/permissions/).
4. Open the dashboard tabs and apply baseline policy.

## Recommended Baseline

- Set app PIN policy and verify admin access.
- Enable required accessibility and device-owner controls.
- Configure Store/App policy before handing device to end user.
- If using kiosk, configure allowed apps first, then enable kiosk mode.
- If using time controls, define app policies before rollout.

## Recovery Baseline

- If setup breaks, use the hidden device-owner clear action from auth/permissions screens.
- If policy appears stale, force a manual config refresh from app/website and re-open the tab.
